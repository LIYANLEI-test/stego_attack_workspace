# SCAD-Lite 10-Sample Pilot

Implement and run a first lightweight prototype of the proposed black-box
carrier-desynchronization attack on current bit-payload methods.

Scope:

- Add `attack_kind=scad` as a 10-sample pilot attack.
- Keep the target quality point at stego-vs-attacked PSNR about 30 dB.
- Run only GSD CIFAR10, MAS/GRDH, MDDM-128 pilot, and Pulsar.
- Summarize bit accuracy/BER, reveal failures, PSNR, and LPIPS.
- Do not launch any formal 500-sample queue.
